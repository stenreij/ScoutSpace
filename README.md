# ScoutSpace

ScoutSpace is een webapplicatie waarmee gebruikers voetbalteams kunnen bekijken en doorzoeken, spelers binnen teams kunnen inzien en spelers kunnen volgen met het oog op scouting. Daarnaast kunnen spelers worden getransfereerd tussen clubs en kunnen teams promoveren of degraderen om zo klasse/divisie bij te houden.


## Doel

Het doel van ScoutSpace is om een overzichtelijk platform te bieden waarin teams, spelers en competities centraal staan. Gebruikers kunnen teams en spelers opzoeken, spelers voorzien van notities en transfers tussen clubs beheren.

## Functionaliteiten

- Overzicht van voetbalteams
- Teams bekijken en filteren
- Spelers binnen een team bekijken
- Spelersinformatie per speler (verschillende gegevens)
- Notities koppelen aan spelers (voor scoutingdoeleinden)
- Spelers transfereren tussen clubs
- Teams promoveren of degraderen (bulk-optie) om klasse/divisie bij te houden

## Architectuur

- **Backend:** ASP.NET Core met een RESTful Web API
- **Architectuur:** Clean/Onion Architecture
- **Database:** Relationele database via Entity Framework
- **Frontend:** Webapplicatie die communiceert met de API
